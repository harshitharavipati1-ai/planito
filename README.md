## 📖 Overview

GreenGrow AI is an Artificial Intelligence-powered sustainable farming platform designed to help farmers, gardeners, and agricultural organizations make better farming decisions.

Using AI image analysis, weather intelligence, plant health monitoring, sustainability analytics, and personalized recommendations, GreenGrow AI reduces excessive fertilizer usage, conserves water, promotes organic farming, and improves crop productivity.

---

# 🎯 Problem Statement

Farmers often face challenges such as:

- Excessive fertilizer usage
- Incorrect watering schedules
- Plant diseases
- Poor soil selection
- Climate uncertainty
- Lack of expert guidance

These issues lead to:

- Reduced crop yield
- Soil degradation
- Water pollution
- Higher farming costs
- Environmental damage

---

# 💡 Solution

GreenGrow AI provides an intelligent platform where users simply upload a plant image.

The AI automatically:

- Identifies the plant
- Detects its health condition
- Determines the growth stage
- Analyzes weather conditions
- Suggests sustainable farming practices
- Recommends fertilizer quantity
- Predicts future plant health
- Provides personalized care plans

# ⚙ Installation

Clone Repository

```bash
git clone https://github.com/harshitharavipati1-ai/greengrow.git
```

Go into Project

```bash
cd greengrow
```

Install Dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Build Project

```bash
npm run build
```

Run Production

```bash
npm start
```

---

# 🔑 Environment Variables

Create a `.env` file.

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY
PORT=3000
```

> **Never commit your `.env` file or real API keys to GitHub.**
